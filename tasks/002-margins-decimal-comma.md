# 002 — Наценка с десятичной запятой молча обрезается

- **Статус:** open
- **Приоритет:** средний. Магазин недобирает наценку, и в интерфейсе этого не видно.
- **Файлы:** `parseMargins()` в `admin/model/extension/currency/nbk.php:14` (и в catalog-копии), `validate()` в `admin/controller/extension/currency/nbk.php:73`, `help_margins` в 4 локалях.

## Проблема
Настройка `currency_nbk_margins` сначала режется по запятой на пары, и только
потом у значения запятая меняется на точку. Поэтому естественный для
русскоязычного админа ввод `EUR:3,5` разбирается как `EUR:3` плюс мусорная
пара `5`, которая молча отбрасывается. В итоге EUR получает наценку 3%
вместо 3,5%.

Комментарий в коде обещает, что как десятичный разделитель подходят и
запятая, и точка («comma or dot accepted as decimal separator»), но для
значений это не работает. Кривые пары (`bad`, `GBP:x` → 0%) тоже
принимаются без предупреждения: `validate()` поле не проверяет.

## Воспроизведение
Проверено на заглушках (в `tests/smoke.php` намеренно не зафиксировано):
`currency_nbk_margins = "EUR:3,5,USD:2"` → `parseMargins()` =
`['EUR' => 3.0, 'USD' => 2.0]`, а ожидалось `EUR => 3.5`.

## Что решить (architect, при необходимости — с пользователем)
Варианты:
1. **Разбор регуляркой** по всей строке:
   `([A-Za-z]{3})\s*:\s*(-?\d+(?:[.,]\d+)?)`. Тогда `EUR:3,5,USD:2` → 3.5 и 2.
   Строки, которые работают сейчас, работать не перестанут.
2. **Отдельный разделитель пар** `;` при сохранении `,` для
   совместимости. Нужно менять `help_margins` во всех 4 локалях.
3. В любом варианте стоит добавить в `validate()` ошибку `error_margins`
   на неразбираемый ввод (новый ключ во все 4 локали), а не терять его
   молча.

Формат хранения менять нельзя: уже сохранённые на VPS значения вида
`EUR:3,USD:2` должны разбираться как прежде.

## Подсказки для критериев приёмки
- В smoke добавлены проверки: `EUR:3,5,USD:2` → `EUR 3.5, USD 2.0`;
  `EUR:3,USD:2` → как раньше; пограничные случаи (пробелы, нижний регистр,
  отрицательная наценка).
- Если добавлена валидация: невалидный ввод не сохраняется, показывается
  ошибка, ключ есть во всех 4 локалях.
- `tests/run.sh` → PASS.
