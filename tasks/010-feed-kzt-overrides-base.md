# 010 — Элемент KZT в фиде перезаписывает базовый курс

- **Статус:** open
- **Приоритет:** низкий. В реальном фиде НБ РК элемента KZT нет, но при его появлении ломаются все курсы.
- **Файлы:** `refresh()` в `admin/model/extension/currency/nbk.php` (и в catalog-копии).

## Проблема
Таблица курсов строится как `$rates = array('KZT' => 1.0)`, затем в цикле
по элементам фида пишется `$rates[$code] = $rate / $quantity`. Если в фиде
окажется `<title>KZT</title>` с курсом ≠ 1, он перезапишет базу, инвариант
«KZT = 1» нарушится, и все кросс-курсы (и курс KZT при default ≠ KZT)
получатся неверными. Ошибки при этом нет.

Найдено Codex'ом при проверке задач 006/007, подтверждено verifier'ом
чтением кода. Существовало и до них.

## Ожидаемое поведение
Элемент фида с кодом KZT игнорируется, базовый курс всегда 1.

## Подсказки для критериев приёмки
- Фикстура/smoke: фид с элементом KZT (курс ≠ 1) даёт те же курсы, что и
  без него, при default KZT и default USD.
- На коде из HEAD проверка падает.
- `tests/run.sh` → PASS.
