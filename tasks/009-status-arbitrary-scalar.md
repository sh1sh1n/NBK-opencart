# 009 — Статус не из «0»/«1» сохраняется без проверки

- **Статус:** open
- **Приоритет:** низкий. Через обычную форму не воспроизводится, нужен подделанный запрос.
- **Файлы:** `validate()` в `admin/controller/extension/currency/nbk.php`.

## Проблема
После 005 массив в `currency_nbk_status` отклоняется, но любой скаляр,
например `'abc'` или `'5'`, сохраняется как есть. Модель и cron считают
его truthy, поэтому модуль включён, а в `setting` лежит мусор.

Найдено architect'ом при проектировании задачи 005.

## Ожидаемое поведение
Сохраняются только `'0'` и `'1'`. Другое значение отклоняется с
`error_status` (ключ добавлен в 005) или нормализуется. Что выбрать,
решает architect.

## Подсказки для критериев приёмки
- Проверка в smoke: POST `currency_nbk_status=abc` не сохраняется как
  `abc`.
- `tests/run.sh` → PASS.
